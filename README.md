# 📍 API CEP

Uma API REST desenvolvida em **JavaScript** para consulta de endereços a partir de um CEP. O projeto foi criado com o objetivo de praticar conceitos de desenvolvimento de APIs, consumo de serviços externos e organização de código utilizando Node.js.

## 🚀 Funcionalidades

- 🔎 Consulta de CEP
- 📦 Retorno de endereço completo em JSON
- ✅ Validação de CEP
- ⚠️ Tratamento de erros
- 🌐 Consumo de API externa (ViaCEP)

## 🛠️ Tecnologias

- JavaScript
-html5
-css3

## 📌 Exemplo de uso

### Requisição

```http
GET /cep/01001000
```

### Resposta

```json
{
  "cep": "01001-000",
  "logradouro": "Praça da Sé",
  "bairro": "Sé",
  "localidade": "São Paulo",
  "uf": "SP"
}
```

## 🎯 Objetivo

Este projeto foi desenvolvido para aprimorar conhecimentos em desenvolvimento de APIs REST, integração com APIs externas e boas práticas de organização de código utilizando JavaScript.
